# Known test failures
#
# One "<test file> :: <test name>" per line, for failures that are accepted
# to be red. An empty list means the suite is expected to be fully green —
# add a line here ONLY for a failure you have deliberately accepted, and put
# a comment next to it saying why.
#
# History: this list held 26 entries until 2026-10-21. All of them were
# fixed rather than accepted:
#
#   translator-request-normalization (4)  real bug — a text-only content
#       array was left as an array instead of being flattened to a string,
#       which strict OpenAI-compatible endpoints (Ollama, gpt-oss, vLLM)
#       reject. Fixed in translator/concerns/message.js +
#       translator/formats/openai.js. A block carrying `cache_control` is
#       still kept as an array — prompt caching lives on the block.
#   golden-url-header (3)               the golden snapshot pinned the app
#       version in the cline auth fingerprint, so every release broke it.
#       The version is normalized in the test now.
#   claude-header-forwarding (1)         asserted the got-scraping TLS
#       spoofing, which was removed from the codebase (dependency dropped,
#       implementation commented out). The test now locks the routing that
#       is actually in place.
#   oauth-cursor-auto-import (8)         asserted an older route contract
#       (single hardcoded path per platform, fuzzy key matching, a
#       "Please login" message). The route now probes several candidate
#       paths, reads one key at a time, and falls back to a manual paste.
#   openai-to-claude (1)                 tool arguments are buffered and
#       sanitized at finish; the test never sent a finish chunk.
#   key-access-handlers (1)             the two catalogue tests load the
#       whole 5.5k-model catalogue out of the DB — more than vitest's 5s
#       default under the parallel run.
#   mimo-free.live (1)                  a live-network test against a
#       provider with an anti-abuse gate. The hermetic part (the Chrome
#       User-Agent that issue #1933 was about) now always runs; the live
#       part is behind RUN_REAL=1, like tests/translator/real/*.
#
# Also fixed alongside them: the Cursor auto-import route no longer calls
# better-sqlite3 on Node >= 24 / Bun, where its native addon SIGSEGVs the
# process (the repo's own DB driver skips it for the same reason).
