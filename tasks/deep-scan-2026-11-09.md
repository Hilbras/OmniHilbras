## Deferred, with reason

- **Vite dev proxy token + a local process.** `sec-fetch-site` stops cross-origin page script, not
  another local process. The dev server has no auth boundary to add one; documented as a loopback
  development trust boundary instead of pretending it is one.
- **ChatGPT/Gemini concurrent turns on one account's profile.** Profiles are now per connection, so
  accounts no longer read each other. Two simultaneous turns on the *same* account still share a
  profile directory; serialising them needs a request queue in the driver, not a one-line fix.
- **DuckDuckGo challenge JS in `node:vm`.** Code generation is disabled and no `process`/`require`
  is exposed, but `vm` is not a sandbox. Removing the risk means moving the solver out of process.
- **Release audit vs suspended publishing.** The success line no longer claims every tag is on npm,
  but `release:audit` still needs npm and GitHub and would report `v1.97.0`–`v1.99.0`. Recording
  them in `knownGaps` is a policy edit that needs the publishing decision.
- **Stale historical `tasks/`, `docs/reports/`, `docs/architecture/phase6-plan.md` numbers.** They
  are history, not current behavior; rewriting them would invent a cleaner past.
- **Small UI polish**: web-cookie guide step numbering and Qwen-specific wording in the generic
  dialog; provider detail shows models from the first account only.
